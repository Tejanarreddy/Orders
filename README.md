# Orders Management System

A simple responsive order-management web application.

## Features
- Add new orders
- Customer name and phone
- Product, quantity and price
- Automatic total calculation
- Pending / Processing / Completed / Cancelled statuses
- Search orders
- Delete individual orders
- Dashboard statistics
- Data saved automatically in browser Local Storage
- Works on phone, tablet and laptop
- No database or internet connection required after the files are loaded

## Run
Open `index.html` in a browser.

For Android, you can upload the folder/project to an online HTML editor such as Replit, run it, and open the preview on your phone.

## Important
This is a front-end version. It stores data in the browser on the device. For multiple users, login, cloud database, admin accounts, payment, or a real Android APK, a backend/database should be added.
